Integral Cryptanalysis Defense for SAILFISH-I

Python

A course project on the lightweight block cipher SAILFISH-I. A reduced-round Python simulation compares the original design with a version that adds an extra key-whitening layer. The modified version loses the balanced property earlier, which weakens integral distinguishers. It is an academic proof of concept, not a full implementation of the cipher.
